Title: **RecallRibbon: Consensus serial-range provenance index**

Draft description:

> RecallRibbon turns prose recall notices into a disjoint serial-range index for a fixed product. Leader and validators independently fetch commit-pinned full documents, check SHA-256, and interpret exact applicability, operative status, included serial ranges and exemptions. Exact agreement drives per-notice subtraction and an endpoint sweep retaining all overlapping notice IDs. Inventory queries count affected units once, preserve provenance, and return REVIEW for unresolved notices. The bounded append-only design prevents silent removal of accepted scope. Includes 33 direct tests and an independent pointwise oracle covering 1,764 configurations. Synthetic fixtures demonstrate documentary scope interpretation, not product-safety truth; publisher authenticity and completeness remain trust assumptions.

This draft contains no live deployment claim. Final proof links will be added after successful execution and state verification.
